# pphv-plugin-skills

Claude Code plugins and skills for the PestPac team, distributed as a plugin
marketplace.

## Install

```
/plugin marketplace add WorkWave/pphv-plugin-skills
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [pestpac-devsupport](pestpac-devsupport/README.md) | Investigate a Jira ticket across Jira, code/GitHub, local SQL, and Slack, and produce an inline root-cause analysis. Mentor-style code review. |

Install a plugin:
```
/plugin install pestpac-devsupport@pestpac
```

See each plugin's README for usage and setup.
